rf-ui - UI customization for the Cerberus RF Online client
=========================================================

[EN] Installation
1. Close the game and the launcher.
2. Copy dinput8.dll into the client folder, where RF_Online_4gb.bin is located.
3. In the launcher settings, enable RFOnline 4gb - it is required, it won't work without it (for now; 2 GB support has been added, stability may be lower).
4. Start the game as usual through the launcher.
5. After entering the world, a small 28x28 px button will appear in the bottom-right corner. rf-ui.log will appear in the client folder, and rf-ui.ini after the first setup.
6. Uninstall: close the game and delete dinput8.dll (and also rf-ui.ini and rf-ui.log if you don't need the settings).
If rf-ui.log says that the client is unknown and the features are disabled, you have a different client version: the mod does nothing and the game runs normally.

[RU] Установка
1. Закройте игру и лаунчер.
2. Скопируйте dinput8.dll в папку клиента, туда, где лежит RF_Online_4gb.bin.
3. В настройках лаунчера обязательно включите RFOnline 4gb - без него работать не будет (пока что; добавлена поддержка 2 ГБ, возможна меньшая стабильность).
4. Запустите игру как обычно через лаунчер.
5. После входа в мир в правом нижнем углу появится маленькая кнопка 28x28 px. В папке клиента появятся rf-ui.log и, после первой настройки, rf-ui.ini.
6. Удаление: закройте игру и удалите dinput8.dll (а также rf-ui.ini и rf-ui.log, если не нужны настройки).
Если в rf-ui.log написано, что клиент неизвестен и функции отключены, значит у вас другая версия клиента: мод ничего не делает, игра работает штатно.
